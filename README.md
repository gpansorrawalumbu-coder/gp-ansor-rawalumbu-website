# GP Ansor Rawalumbu — Online Admin
1. Buat project gratis di Supabase.
2. Jalankan `supabase.sql` di SQL Editor.
3. Buat Storage bucket public bernama `news-images`.
4. Buat akun admin di Authentication > Users.
5. Isi `config.js` dengan Project URL dan anon key.
6. Masukkan logo asli sebagai `assets/logo-gp-ansor.png` dan foto kegiatan sebagai `kegiatan-1.jpg` s/d `kegiatan-4.jpg`.
7. Upload folder ke GitHub Pages/Cloudflare Pages.
Admin dibuka melalui `admin.html` dan login memakai akun Supabase.
